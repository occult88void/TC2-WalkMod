# Bootstrap14: Host и Component Host table

## Назначение

Bootstrap14 — read-only диагностическая сборка для уточнения связи между Component Host, его таблицей компонентов и нативной lifecycle-цепочкой.

## Безопасность

- Нет inline hooks.
- Нет code patches.
- Нет записей в память игры.
- Не нажимать Leave ради этого теста.
- Не проверять выход в открытый мир в рамках этого сбора.
- Сбор ограничен двумя состояниями: Freedrive и HQ.

## Что собирается

Для каждого состояния:

1. Host root: до 0x2000 байт.
2. Host pointer fields: +0x650, +0x658, +0x6D0, +0x6D8 и дополнительный кандидат +0x1E68.
3. Для каждого найденного объекта: до 0x400 байт объекта, настоящий vtable pointer из первого qword, до 32 qword vtable.
4. Для vtable entries, указывающих на executable-код внутри TheCrew2.exe: окно кода 0x100 байт с RVA и индексом слота.
5. Component table из Host +0x1DD8, её metadata из +0x1DE0 и selector из +0x1DE8.
6. Двойная проверка стабильности снимков table и selector перед разбором.
7. Все ненулевые внешние pointer entries таблицы (до 128 записей): объект и vtable.
8. Отдельная фиксация selector offsets +0x02, +0x03, +0x04, +0x23 и выбранных ими индексов.
9. Для компонента, выбранного selector +0x03, чтение поля +0xDF8 и захват его цели, если значение является правдоподобным внешним указателем.
10. Дополнительные окна native callees, найденных при разборе lifecycle-вызовов.

Файлы object и actual_vtable имеют разные имена. В этой версии vtable никогда не читается из начала object dump.

## Порядок теста

1. Запустить игру с этой диагностической DLL.
2. В Freedrive на автомобиле нажать Ctrl+Shift+F10 один раз.
3. Перейти в HQ и дождаться пешего персонажа.
4. Нажать Ctrl+Shift+F11 один раз.
5. Дождаться записи BOOTSTRAP14_SEQUENCE_COMPLETE в TC2_Walkmod.log.
6. Передать целиком папку TC2_runtime_capture/capture_* и TC2_Walkmod.log.

Не запускать F10/F11 многократно в одном процессе. Никаких дополнительных сценариев в этой сборке нет.
