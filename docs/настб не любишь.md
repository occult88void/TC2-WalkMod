## Последний результат работы

Проверен архив `TC2_runtime_capture текущий.zip`, каталог `capture_17324_12203687`. Диагностическая DLL выполнила сбор до строки `FACTORY_SEQUENCE_COMPLETE`. Timestamp и SizeOfImage соответствуют ожидаемой сборке, пропущенных при сканировании байтов нет.

Для классов AiBotFreerideSpawner, AIPlayerBotFreeride и AvatarTC2 совпадений хешей не обнаружено. Единственное совпадение MissionAtomSpawn по RVA `0x044E8A08` находится в `.xcode1`. Все 384 байта сохранённого контекста совпадают с данными предоставленного EXE на диске. Unwind-границ нет. Оснований объявлять этот участок обработчиком Spawn нет.

Разобраны 11 дополнительных кодовых окон. Функция `0x4301E0` обновляет зарегистрированную ссылку на существующий объект. Создание по архетипу и назначение управления локальному игроку здесь не подтверждены. `0x119EBE0` получает и проверяет существующий объект, а `0x119FC60` читает transform с дополнительными fallback-ветками.

Повторно проверена альтернативная lifecycle-цепочка `0x1FA530`. Она вызывает `0x772880` и после успешного результата связывает объекты через несколько методов, включая `0x841D60`. Имеющееся начало `0x772880` обрывается на `0x772A78`. Нужные ветки режимов `0x400/0x800` находятся вне сохранённого диапазона. Применимость этого пути к пешему аватару остаётся неизвестной.

Дополнительно проверены доступные открытые реализации. Исходники VR-мода tc2vr содержат работу с камерой и сведения о структурах движка. Проверенного решения создания управляемого пешего аватара из них не получено. Адреса другой сборки требуют независимого сопоставления. [Исходники tc2vr](https://github.com/PhialsBasement/tc2vr)

## Состояние реализации

Рабочий выход из транспорта в Freedrive, передача управления пешему аватару, сохранение исходного автомобиля и возврат в него не реализованы. Probe 18 подтвердил выполнение диагностики, но не закрыл основной технический пробел. Новая диагностическая DLL после этого захвата не выпускалась.

Для продолжения без последовательной пересылки небольших захватов требуется среда с установленной игрой и возможностью непосредственно проводить цикл анализа, запуска и проверки поведения. GitHub Actions подтверждает компиляцию, игровой результат требует отдельной проверки.

Подробные результаты предыдущей сборки, SHA-256 DLL и ограничения сохранены в [TEST_RESULTS.md](TEST_RESULTS.md). Последний результат захвата ранее зафиксирован commit `bee918a` в ветке `development-2026-11-22`.
