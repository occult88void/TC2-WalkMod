# Walkmod Test 01: AllowedOutOfGameplayZone

## Изменение

Один байт в базовом archetype `CITEntityGeographicalSpot`:

- ID: `21E4830700000000`
- Поле: `AllowedOutOfGameplayZone`
- Исходное значение: `00`
- Тестовое значение: `01`
- Файл: `entity/generated/archetypes.entities.bin`

Патч не меняет EXE/DLL, не устанавливает hooks и не затрагивает память процесса.

## Цель

Проверить, влияет ли это поле на возможность уже активированного пешего персонажа выходить за границу gameplay zone. Поле принадлежит `CITEntityGeographicalSpot`, поэтому оно **не считается глобальным разрешением ходьбы** и не гарантирует появление Leave в Freedrive.

## Порядок

1. Оставить исходный DZ.Blood Walkmod включённым, чтобы сохранить существующий Leave из HQ Rally/GP.
2. Импортировать этот тест как отдельный мод в PitCrew.
3. Включить его и скомпилировать.
4. Запустить игру обычным способом, без дополнительных DLL.
5. Войти в HQ Rally или HQ GP, использовать штатный Leave и пройти тот же маршрут за пределы HQ, на котором ранее наблюдалось ограничение.
6. Сравнить поведение с исходным модом.

## Критерий

- Если граница/ограничение изменилось, поле влияет на этот путь, но это ещё не доказывает универсальный выход из транспорта.
- Если ничего не изменилось, гипотезу о влиянии этого поля на пеший режим закрываем.
- При побочных эффектах отключить только Test 01 и повторно скомпилировать.

## Ограничение

Тест не добавляет действие Leave в Freedrive и не создаёт Avatar. Он проверяет только один конкретный data-side gate.
