THE CREW 2 WALKMOD - STARTER BUILD
==================================

Что это
-------
Это ПЕРВЫЙ загрузочный/диагностический каркас, а не готовая ходьба.
Он собирается в 64-битную DLL dinput8.dll, передаёт вызовы настоящей
системной dinput8.dll из Windows и создаёт лог TC2_Walkmod.log рядом
с TheCrew2.exe при первом обращении к DirectInput.

В этой версии НЕТ перехвата Leave, создания аватара или изменения
управления. Ничего в памяти игры она не меняет. Это сделано специально:
сначала проверяем безопасную загрузку прокси в конкретной установке игры.

Сборка без Visual Studio на компьютере
--------------------------------------
Нужен аккаунт GitHub. Устанавливать Visual Studio или компилятор не надо.

1. Открой https://github.com/new и создай пустой репозиторий.
   Название, например: TC2-Walkmod.
   Можно оставить Public или выбрать Private.
2. Распакуй этот ZIP на компьютере.
3. На странице нового репозитория нажми Add file -> Upload files.
4. Перетащи ВСЁ содержимое распакованной папки (включая папку .github)
   в окно загрузки GitHub. Важно: загружай содержимое папки, а не сам ZIP.
5. Нажми Commit changes.
6. Открой вкладку Actions. Должен появиться запуск
   "Build TC2 Walkmod bootstrap". Если GitHub спросит разрешение,
   нажми I understand my workflows, go ahead and enable them.
7. Дождись зелёной галочки у сборки, открой её и найди блок Artifacts.
8. Скачай TC2-Walkmod-bootstrap-x64.zip и распакуй его.

Установка и проверка
--------------------
1. Найди папку игры, где находится TheCrew2.exe.
2. Сделай резервную копию оригинального dinput8.dll, если он уже лежит
   рядом с TheCrew2.exe. Не трогай dinput8.dll в папке Windows/System32.
3. Скопируй собранный dinput8.dll рядом с TheCrew2.exe.
4. Запусти игру обычным способом.
5. После запуска проверь, появился ли рядом с TheCrew2.exe файл
   TC2_Walkmod.log.
6. Если игра не запускается, сразу убери наш dinput8.dll из папки игры
   и верни резервную копию оригинального файла.

ВАЖНО
-----
- Не запускай игру с этим прокси в сетевых режимах, если не уверен,
  что модификация DLL разрешена правилами игры. Для первых тестов
  используй офлайн-режим.
- Не загружай в GitHub исполняемые файлы игры или игровые архивы.
  Для сборки нужны только исходники из этого пакета.
- Если Actions не запускается или не удаётся найти Artifact, остановись
  и пришли скриншот страницы. Ничего дополнительно устанавливать не надо.
- Это диагностический этап. Успешная загрузка DLL ещё не означает,
  что ходьба уже работает.
