# Bootstrap 11: read-only component-host snapshots

Дата: 2026-11-17

## Цель

Сравнить состояние глобального component-host candidate в трёх режимах:

1. Freedrive, игрок находится в автомобиле.
2. HQ/house, игрок управляет пешим персонажем.
3. Открытый мир, пеший персонаж находится снаружи HQ/house.

Основной вопрос: меняется ли таблица компонентов, её selector table или объекты компонентов при переходе между транспортным и пешим режимами.

## Что делает сборка

- Использует проверенный пассивный Bootstrap 09 как основу.
- Не использует MinHook.
- Не устанавливает inline hooks.
- Не меняет код игры и не записывает данные в память игры.
- Читает PE fingerprint, type descriptors и известные native code windows.
- Снимает глобальный указатель по RVA 0x343C630, root window 0x2000, указатели +0x1DD8 и +0x1DE8, их таблицы и доступные объекты.
- Для каждой записи таблицы сохраняет первые 0x100 байт, vtable и значение по +0x18.
- Отдельно помечает индекс 0x1C как кандидат из внешних заметок. Его назначение локально пока не доказано.

## Последовательность в игре

Запускать только на сборке Bootstrap 11 из этой ветки.

1. Загрузить The Crew 2 и остаться в Freedrive внутри машины. Нажать Ctrl+Shift+F10.
2. Дождаться записи SNAPSHOT_TRIGGERED: label=01_FREEDRIVE_VEHICLE, перейти в HQ или дом и встать пешком. Нажать Ctrl+Shift+F11.
3. Дождаться записи SNAPSHOT_TRIGGERED: label=02_HQ_PEDESTRIAN, выйти пешком из HQ/дома в открытый мир. Нажать Ctrl+Shift+F12.

Каждый этап ждёт свою комбинацию до 10 минут. Если третий режим недоступен, первые два снимка всё равно сохраняются.

## Результаты

Файлы создаются в папке The Crew 2/TC2_runtime_capture/capture_<pid>_<tick>/.
Основной журнал: The Crew 2/TC2_Walkmod.log.

Для сравнения важны строки:
- COMPONENT_HOST_ROOT
- COMPONENT_HOST_ENTRY
- SLOT_1C_CANDIDATE_UNVERIFIED
- COMPONENT HOST SNAPSHOT BEGIN/END

## Ограничения

Это диагностическая сборка, не мод ходьбы. Она не создаёт Avatar и не переключает управление. Значение +0x1C не объявляется camera-owner до проверки по локальным снимкам и коду.
